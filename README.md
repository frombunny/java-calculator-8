# java-calculator-precourse

## 구현할 기능 목록 정리

----

### 입력 기능 (InputView)

- [x] `"덧셈할 문자열을 입력해 주세요.\n"`라는 문자열을 출력한다.
- [x] 사용자로부터 문자열을 입력받는다.
- [x] 입력된 문자열을 반환한다.

### 입력 검증 기능 (InputValidator)

- [ ] 문자열을 전달받아 사용자의 입력을 검증한다.
- [ ] 만약 사용자의 입력이 올바르지 않을 경우, `IllegalArgumentExcpetion`을 발생시킨다. (Application에서 이 예외를 catch하여 애플리케이션을 종료시킨다.)
    - [ ] 단, `""`의 경우에는 정상 입력으로 처리한다.
    - [ ] `null`, 공백을 입력한 경우
    - [ ] 기본 구분자(쉼표, 콜론) 또는 지정된 커스텀 구분자, 양수 외의 다른 문자를 입력한 경우

### 커스텀 구분자 추출 기능 (CustomDelimiterExtractor)

- [ ] 문자열에서 커스텀 구분자를 추출하여 반환한다.

### 구분자 기준 구분 기능 (InputTokenizer)

- [ ] 구분자를 기준으로 구분하여 `List`에 담아 반환한다.

### 계산 기능 (Calculator)

- [ ] `List`를 전달 받아 덧셈을 수행하여 값을 반환한다.

### 결과 출력 기능 (OutputView)

- [ ] `"결과 : %d"`의 형태로 결과를 출력한다.
