# java-calculator-precourse

## 구현할 기능 목록 정리

----

### 입력 기능

- [x] `"덧셈할 문자열을 입력해 주세요.\n"`라는 문자열을 출력한다.
- [x] 사용자로부터 문자열을 입력받는다.

### 입력 검증 기능

- [x] 사용자의 입력을 검증한다.
- [x] 만약 사용자의 입력이 올바르지 않을 경우, `IllegalArgumentExcpetion`을 발생시킨다. (Application에서 이 예외를 catch하여 애플리케이션을 종료시킨다.)
    - **정상 입력**
        - [x] 기본 구분자(쉼표, 콜론)와 양수로 이루어진 경우 : `"2:1.3"`
        - [x] 커스텀 구분자와 양수로 이루어진 경우 : `"//;\n1;2;3"`
        - [x] 커스텀 구분자와 기본 구분자(쉼표, 콜론), 양수로 입력이 이루어진 경우 : `//;\n1;2,3:4`
        - [x] 빈 입력의 경우 : `""`
        - [x] 수가 두자리 이상의 수일 경우 : `2,3,435`
        - [x] \가 커스텀 구분자로 들어올 경우 : `//\\n2:3:4`
        - [x] 숫자 사이 구분자가 연속으로 들어올 경우 : `//;\n2;;3;4`
        - [x] 커스텀 구분자로 공백을 입력할 경우 : `// \n2 3 4`

    - **비정상 입력**
        - [x] 커스텀 구분자와 기본 구분자(쉼표, 콜론), 양수 외의 문자가 존재할 경우 : `"//;\n1;2,3@4"`
        - [x] 공백 입력의 경우 :  `" "`
        - [x] 커스텀 구분자가 ‘문자열’일 때 : `"//;;\n2;3;4"`
        - [x] 커스텀 구분자가 ‘숫자’일 때 : `"//2\n2;3;4"`

### 커스텀 구분자 추출 기능

- [x] 문자열에서 `//`와 `\n` 사이의 문자를 커스텀 구분자로 추출한다.

### 구분자 기준 구분 기능

- [x] 기본 구분자(쉼표, 콜론) 또는 커스텀 구분자를 기준으로 숫자들을 분리하여 반환한다.

### 계산 기능

- [x] 구분된 수들의 합을 구한다.

### 결과 출력 기능

- [x] `"결과 : %d"`의 형태로 결과를 출력한다.
