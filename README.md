# java-calculator-precourse

## 구현할 기능 목록 정리

----

### 입력 기능

- [x] `"덧셈할 문자열을 입력해 주세요.\n"`라는 문자열을 출력한다.
- [x] 사용자로부터 문자열을 입력받는다.

### 입력 검증 기능

- [ ] 사용자의 입력을 검증한다.
- [ ] 만약 사용자의 입력이 올바르지 않을 경우, `IllegalArgumentExcpetion`을 발생시킨다. (Application에서 이 예외를 catch하여 애플리케이션을 종료시킨다.)
    - [ ] `""(빈 입력)`의 경우에는 정상 입력으로 처리한다.
    - [ ] 기본 구분자(쉼표, 콜론) 또는 지정된 커스텀 구분자, 양수로 구성되어 있지 않은 경우는 비정상 입력으로 처리한다.

### 커스텀 구분자 추출 기능

- [ ] 문자열에서 `//`와 `\n` 사이의 문자를 커스텀 구분자로 추출한다.

### 구분자 기준 구분 기능

- [ ] 기본 또는 커스텀 구분자를 기준으로 숫자들을 분리하여 반환한다.

### 계산 기능

- [ ] 구분된 수들의 합을 구한다.

### 결과 출력 기능

- [ ] `"결과 : %d"`의 형태로 결과를 출력한다.
